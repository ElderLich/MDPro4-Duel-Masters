# Duel Masters v0.2.0-preview.1

This development preview adds Duel Masters presentation and shield handling to
the maintained card package, with complete native games and saved response
replays covering the new rules fix.

**Required host integration:** local MDPro4 branch `Duel-Masters`, commit
`e84c3009c`. That source branch has not been pushed, and this release contains
no compiled MDPro4 client. Installing the YPK alone does not add the new host
interface to an existing public client.

## Included

- 1,017 playable records, 15 starter decks and 124 approved full printed-card
  scans, using explicit package card membership.
- Complete printed DM cards in the local host, with matching proportions and
  preserved frames. Missing images use the existing fallback.
- DM types, civilizations, races, mana costs and power in the sidebar and full
  reader, without false YGO statistics or archetype annotations.
- Five automatically placed, numbered shields per player; protected identities,
  persistent selection markers and one reviewable multi-shield confirmation.
- An event-updated shield counter instead of compatibility LP on the HUD.
  Native LP, damage and win state are unchanged.
- A fix for repeatedly offering a creature Shield Trigger that cannot summon
  because the battle zone is full.

## Validation

Fifteen Python checks and 155 Lua regressions passed. All 1,017 playable records
initialized in the deployed Windows core. Five complete nine-turn native games
covered creature-trigger acceptance/decline, spell-trigger destruction, double
breaking and the full-zone regression. All five saved YRP1 files were read back
from disk and reproduced their full native event streams without Lua errors.

Local Unity checks passed: 12 rendering/resource, 26 shield-privacy, 13 card-facts,
10 HUD/restoration and 28 selection-handler assertions. The real selection
handler returned `020102` for offered indexes 1 and 2, kept identities hidden,
prevented duplicate confirmation and restored owned state. Sidebar/full-reader
screenshots and standard-card restoration were inspected. These callback checks
do not claim physical pointer/gamepad or multiplayer acceptance.

All five saved files also completed through the real Unity replay player:
three normal-view and two Free View cases, each reaching its turn-nine win,
result confirmation and complete exit. Hidden-shield observations and
movement-driven shield-counter checks passed. Views closed, borrowed settings
were restored and the final Console contained zero warnings or errors.
See [the acceptance record](https://github.com/ElderLich/MDPro4-Duel-Masters/blob/v0.2.0-preview.1/docs/acceptance.md).
Replay seeking and physical pointer/gamepad input were not certified.

## Limits and installation

The first target remains the inherited DM-01–DM-13-era collection and
game-original extras. There are five native shield slots; five occupied battle
slots were exercised. More shields, unrestricted battle zones and current
Japanese mechanics are not implemented. Full-field evolution through effects or
Shield Trigger remains a preexisting limitation, including Q-tronic's printed
trigger and Wolfis's separate granted-trigger path. Multiplayer secrecy and
non-Windows cores have not been validated. There are 897 database IDs without
reviewed artwork. No approved DM back was found, so the existing protector stays
in use.

Download `MDPro4-Duel-Masters-v0.2.0-preview.1.ypk` and its `.sha256` sidecar.
Replace the previously installed DM YPK in `Expansions`, keeping only one
active DM version to avoid duplicate databases. Retain older downloads under
`Releases`, outside the active expansion folder. Enable expansions, restart
and copy a packaged `deck/*.ydk` into `Deck`. Private
compatibility tests currently require the host deck-check bypass and forty DM
cards plus the rules support card `24000000`. Both peers need compatible host
code and the same package.

Local release payloads are stored under `Releases/v0.2.0-preview.1/`; installable
downloads belong to GitHub Releases. Published tags and files are immutable.

Original YGOPro-DM creators **Hello23-Ygopro** and **szefo09** remain credited;
GPL-3.0 is retained. Duel Masters names, text and artwork belong to their
respective rights holders.
