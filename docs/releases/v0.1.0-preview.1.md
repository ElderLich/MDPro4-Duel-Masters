Initial development package for the existing Duel Masters card collection.

- 1,017 card scripts, 1,021 database records, 15 starter decks and 124 verified full-card scans.
- MDPro4-native script loading, seeded randomness, corrected deck validation and breaker choices.
- Automatic opening shields without placement prompts or identity-bearing placement hints.
- Original YGOPro-DM authors Hello23-Ygopro and szefo09 credited; GPL-3.0 retained.

Validation: 155 Lua regressions, 14 Python checks, native card initialization and opening response tests, and Unity archive-lifetime checks.

This preview uses the original YGO host presentation and five physical shield slots. Dedicated DM visuals, full-duel/replay acceptance and complete modern-rule support are not part of this version.

Install the `.ypk` in `Expansions`, enable expansions, restart, and copy a packaged starter `.ydk` into `Deck`. See the included README. Both players must use the same package.

Source: `2064fc4012331762bfe441714061cbb1a20271a3`. Download the `.ypk` and verify its `.sha256` sidecar. Published files are immutable; future changes receive a new tag.
